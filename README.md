# ドット商事 3F

会社のフロアで社員が働く様子を描いた、2D ドット絵のオフィスゲームです。ブラウザだけで動きます（ビルド不要）。

## 遊び方

`index.html` をブラウザで開きます。

| 操作 | キー |
| --- | --- |
| 移動 | ←↑↓→ / WASD、または画面クリック |
| 話す・調べる・作業 | Space / Z / Enter |
| スマホ | 画面下の十字キーと A ボタン |

- ▼印のデスクがあなたの席です。座って Space を押すとタスクが進みます。
- 集中力が減ったら、ラウンジのコーヒーや自販機で回復できます。
- 社員 8 人はそれぞれ作業・休憩・会議などを自動で行います。
- 仕事をしないままぶらぶらしていると、部長に目をつけられます。
  - サボり 35 分（ゲーム内）で「部長の視線を感じる…」と警告が出ます。
  - サボり 50 分で部長が追いかけてきて、捕まると怒られます（集中力 -10、怒られた回数 +1）。
  - 部長が来る前に自分の席に座れば見逃してもらえます。逃げ回ってまくこともできます。
  - ソファでくつろいでいると、サボり時間が 2 倍の速さで増えます。昼休みと定時後は怒られません。
- ゲーム内の 1 分は現実の 1 秒。9:00 から始まり、19:30 で翌日に進みます。
