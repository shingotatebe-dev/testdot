# ドット商事 3F

会社のフロアで社員が働く様子を描いた、2D ドット絵のオフィスゲームです。ブラウザだけで動きます（ビルド不要）。

## 遊び方

`index.html` をブラウザで開きます。

| 操作 | キー |
| --- | --- |
| 移動 | ←↑↓→ / WASD、または画面クリック |
| 話す・調べる・作業 | Space / Z / Enter |
| スマホ | 画面下の十字キーと A ボタン |

- ▼印のデスクがあなたの席です。座って Space を押すとタスクが進みます。
- 集中力が減ったら、ラウンジのコーヒーや自販機で回復できます。
- 社員 8 人はそれぞれ作業・休憩・会議などを自動で行います。
- ゲーム内の 1 分は現実の 1 秒。9:00 から始まり、19:30 で翌日に進みます。
